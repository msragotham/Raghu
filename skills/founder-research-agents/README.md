# Founder Research Agents

A downloadable research skill for evaluating practical business opportunities in Tamil Nadu and India.

## Files

- `SKILL.md` — Full reusable instructions for the 11-agent framework, Mode A and Mode B, pain-point-first research, the machinery → service → product rotation, India import-versus-local sourcing analysis, report format, evidence standards, adaptive feedback, and Tamil output preferences.
- `README.md` — This overview and usage guide.

## Installation

Copy the `founder-research-agents` folder into the skills directory supported by your AI assistant. Keep `SKILL.md` at the root of that folder. If your assistant supports uploading skill files directly, upload `SKILL.md`; use this README as the quick-start reference.

## Use it

### Mode A — Teach the Task

Ask for a practical walkthrough of a task, such as: “Teach me how to import a CNC machine from China to Tamil Nadu.” The skill will clarify the goal, explain the process and tools, and finish with an actionable checklist.

### Mode B — Business Research

Ask for a single opportunity evaluation, such as: “Research whether renting specialized laser-cutting machines to small fabricators in Tamil Nadu can work.” The report uses all 11 agent lenses, starts with customer pain, and ends with a Go / No-Go / Validate decision and execution steps.

By default, reports are written in Tamil with useful English business terminology retained. Ask for another language or format whenever you prefer.

## What the research checks

Every Mode B report compares importing with local sourcing. It examines supplier evidence, MOQ and trade terms, freight and other landed-cost components, current Indian compliance requirements, comparable local prices, margins, working capital, and break-even. Unverified quotes and uncertain requirements are labeled; the report does not treat a low factory price as proof of profitability.

The opportunity discovery rotation is machinery sales/rental/leasing → service startup → product startup, then repeat. Each report still focuses on one idea.

## Important usage note

The skill is a research and decision-support framework. It requires current source checks for changing facts and does not replace customs, tax, legal, engineering, or other qualified professional advice where that is needed. It must clearly mark estimates and unresolved validations.
