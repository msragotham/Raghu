# Skills Library

This repository is the home for skill packages created or collected with Codex. Keep each skill in its own folder under `skills/`, with its `SKILL.md` and any README, references, or metadata needed to use it. When adding a skill, check for repeated instructions and remove exact duplication while preserving useful summaries and checklists.
