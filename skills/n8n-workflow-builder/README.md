# n8n Workflow Builder

A reusable skill for planning, building, validating, and safely testing n8n workflows with connected n8n tools.

## Files

- `SKILL.md` — Complete workflow-building instructions.
- `agents/openai.yaml` — Display name and short description metadata.
- `references/research-and-principles.md` — Research sources and design principles used by the skill.

## Use it

Ask for a new n8n workflow or a change to an existing one. The skill plans the workflow, uses the connected instance's current node definitions and validation tools, handles credentials carefully, tests with synthetic data when safe, and leaves production activation deliberate.
